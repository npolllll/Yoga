## Исправленные дефекты, найденные тестами
- Устаревший ответ `/api/me/state` перезаписывал оптимистичное обновление (избранное после входа не отображалось).
- Клик до загрузки состояния пользователя трактовался как действие гостя.
- Описания полей админки (функции) передавались из серверного компонента в клиентский → ошибка страницы редактора.
- Переключение языка через клиентскую навигацию сохраняло скрытую копию страницы другого языка; теперь — полная загрузка документа.
- После входа/выхода (серверное действие + редирект) шапка и состояние участника не обновлялись до перезагрузки: провайдер в layout читал состояние только при монтировании. Теперь обновляется при смене auth-cookie (навигация, фокус вкладки).
- После «Восстановить версию» открытый редактор показывал старый черновик (следующее сохранение конфликтовало бы). Теперь редактор принимает серверную ревизию, если нет локальных правок.
- Проверка пересечений 3D не учитывала голову: пучок уходил в пол на 14 см в стойке на предплечьях; в стойке на голове опора приходилась на пучок, а не на макушку. Добавлены точки головы, персонаж 1.2.0 (пучок на теменно-затылочной части).
- Очередь рендера считала старый рендер готовым после смены персонажа (сравнивала с сохранённым, а не текущим хэшем).

## Не выполнено / ограничения
- Lighthouse по реальным пользователям (полевые CWV) — только после публичного запуска.
- Проверка доступности из РФ — нужна внешняя сеть/устройства (см. DEPLOYMENT §5).
- Экспертная проверка контента и анимаций — нет рецензента.
