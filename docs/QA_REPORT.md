## Исправленные дефекты, найденные тестами
- Устаревший ответ `/api/me/state` перезаписывал оптимистичное обновление (избранное после входа не отображалось).
- Клик до загрузки состояния пользователя трактовался как действие гостя.
- Описания полей админки (функции) передавались из серверного компонента в клиентский → ошибка страницы редактора.
- Переключение языка через клиентскую навигацию сохраняло скрытую копию страницы другого языка; теперь — полная загрузка документа.

## Не выполнено / ограничения
- Lighthouse по реальным пользователям (полевые CWV) — только после публичного запуска.
- Проверка доступности из РФ — нужна внешняя сеть/устройства (см. DEPLOYMENT §5).
- Экспертная проверка контента и анимаций — нет рецензента.
