## Утверждено владельцем (мастер-промпт v2.0)
- ✅ Бренд **BALANCE**; продукт — образовательная платформа (балансы на руках, стойки, инверсии, переходы).
- ✅ Языки RU и EN; маршруты `/ru/...`, `/en/...`.
- ✅ Аудитория: примерно поровну Россия и другие страны.
- ✅ Первый релиз — полный продукт: 40–50 асан, у каждой своя 10-секундная 3D-анимация (30 fps, 300 кадров, без звука), программы, аккаунты, прогресс, админка.
- ✅ Бюджет на сервисы/инструменты/подрядчиков: €0. Инфраструктура: Supabase + Vercel. До получения доступов — локальная разработка.
- ✅ Собственная админка внутри приложения, без Payload/Strapi.
- ✅ Персонаж: один стилизованный 3D-персонаж, похожий на героиню PDF, но не обязан копировать лицо; создаётся Blender Python.
- ✅ Для практики хранятся три состояния: Not Started / In Progress / Learned; выполнение шагов программ хранится отдельно; `stepKey` — постоянный UUID.

## Рабочие допущения 🟡
- 🟡 Четвёртый уровень: ключ `expert`, подпись «Эксперт/Expert»; переопределяется в админке (Настройки → Подписи уровней), например на «Pro».
- 🟡 Визуальная система: светлая минималистичная основа, мягкие розово-лиловые акценты PDF, композиция экранов по JPG. Всё — через токены в `src/app/globals.css`.
- 🟡 Шрифты: Lora (заголовки, serif) и Manrope (интерфейс) — SIL OFL, кириллица+латиница, раздаются с нашего домена (без Google Fonts в рантайме). Hagrid/Gordita из PDF коммерческие — не используются.
- 🟡 Санскрит отображается упрощённой латиницей (Bakasana). Проверено: в Lora/Manrope нет глифов IAST с точкой снизу (ṛ, ṣ, ṭ…); IAST хранится только в альтернативных названиях для поиска.
- 🟡 Каталог стартует с 44 асан (6 Beginner / 13 Intermediate / 16 Advanced / 9 Expert; 7 категорий) и 22 подготовительных упражнений — `content/catalog.json`. Распределение по уровням — редакционное, требует проверки преподавателем.
- 🟡 Публикация без экспертной проверки по умолчанию запрещена (`site_settings.allow_unreviewed_publish = false`). В dev/staging включена, чтобы проверять сценарии; такие страницы показывают предупреждение «ещё не проверено преподавателем».
- 🟡 Видеоуроки: поле на каждый язык (`video.ru`, `video.en`), провайдер `youtube | vk | rutube | other`. Ссылки добавляются только после реальной проверки (доступность, встраивание, соответствие варианту позы). Без проверенной ссылки показывается честное «урок пока не добавлен».
- 🟡 Медиа анимаций хранятся в репозитории (`public/media/poses/...`) и раздаются CDN Vercel; загрузки из админки — в Supabase Storage (бакет `media`). URL строится через `mediaUrl()` + `NEXT_PUBLIC_MEDIA_BASE_URL`, поэтому хостинг можно заменить.
- 🟡 Тексты на телах страниц — простой текст (абзацы, списки «- »), без HTML: исключает XSS из админки.
- 🟡 Пропорции персонажа: «мягкие», голова ≈ 1/5.5 роста (не чиби), чтобы крупная голова не закрывала точки опоры и позы читались.
- 🟡 Рендер: Blender 5.2.4 LTS, Cycles CPU (контейнер без GPU), 30 fps; статичные фазы удержания рендерятся с переиспользованием кадров, если поза не меняется.
- 🟡 Персональные данные: email + пароль (Supabase Auth), имя необязательно. Экспорт JSON и удаление аккаунта самим пользователем.
- 🟡 Персонаж 1.2.0: пучок на теменно-затылочной части головы (не на макушке), чтобы в стойках на голове опора была на макушке, а затылок оставался плоским для стоек на плечах. Узнаваемость пучка спереди ниже — осознанный компромисс в пользу правильной техники.
- 🟡 Анимации проходят автоматическую проверку каждого кадра (пол, опоры, центр масс, ограничения суставов) и уникальность постеров (перцептивный хэш ≥ 12 бит до любого другого постера). Для похожих поз ракурс выбирается так, чтобы был виден отличительный признак; подбор — `pipeline/poster_probe.sh` (Cycles), превью Workbench хэш не предсказывают.
- 🟡 Постер перехода — устойчивая конечная поза: проверка центра масс выполняется на кадре постера, кадр середины перехода её не проходит.
- 🟡 Поведение кэша Next.js 16 (Cache Components), принятое как есть и задокументированное:
  - несуществующий slug динамического маршрута (позы, программы): первый «холодный» ответ может прийти со статусом 200 — оболочка уже отправлена, когда страница вызывает `notFound()`; Next.js добавляет `<meta name="robots" content="noindex">`, повторные ответы — 404. Строгий 404 на первом запросе требует проверки slug в `src/proxy.ts` (документированный путь Next.js; не сделано — нужен кэш списка slug и согласование с публикацией);
  - страница, пререндеренная при сборке, после первой публикации может один раз отдать предыдущую версию, затем свежую;
  - если запрос к странице запустил фоновую регенерацию до завершения публикации/сохранения настроек, в кэш может попасть старая версия до следующей инвалидации или истечения `cacheLife("hours")`. Обход: повторить сохранение. Редкий случай; кандидат на кнопку «Обновить публичный кэш» в админке.
- 🟡 Ссылка на главную в шапке без prefetch; карточки библиотеки без `fetchPriority="high"`: предзагруженный маршрут с высокоприоритетным изображением добавляет preload этого изображения на каждой странице и отнимает канал у её LCP-изображения.
- 🟡 Брендовые иллюстрации экспортируются в размере показа (×~2,6 для плотных экранов), а не в размере рендера.
- 🟡 Шрифты Lora/Manrope (fontsource, SIL OFL) раздаются как статические файлы `public/fonts/v5/` (`scripts/fonts-sync.py`, `src/app/fonts.css` — те же `@font-face` и `unicode-range`), кэш `immutable`. Предзагружается только Manrope (основной текст): FCP 1,8 → 1,4 с, CLS ≈ 0. Предзагрузка всех 4 файлов (≈97 КиБ) ускоряла FCP до 0,9 с, но ухудшала LCP (шрифты отнимали канал у LCP-изображения) — отвергнута по замерам.

## Открытые вопросы ❓ (не блокируют разработку)
- ❓ Кто преподаватель-рецензент (аккаунт с ролью reviewer). Без него контент остаётся «без экспертной проверки».
- ❓ Юридический статус и юрисдикция оператора данных: GDPR / 152-ФЗ (локализация данных россиян в РФ), регион Supabase. Соответствие не заявляется — см. `docs/DEPLOYMENT.md`.
- ❓ Доступность Vercel/Supabase/YouTube из России: YouTube в РФ в 2026 г. ограничен (частичная блокировка), зарубежные CDN могут замедляться провайдерами. Требуется фактическая проверка перед запуском и, возможно, альтернативные видеоисточники (VK Видео/Rutube) для RU-уроков.
- ❓ Vercel Hobby разрешает только некоммерческое использование — если проект коммерческий, нужен Pro (платно, требует решения владельца).
- ❓ Реальные контакты и соцсети проекта (в PDF — шаблонные, не переносятся).
- ❓ Финальные тексты политики конфиденциальности и условий — нужна проверка юристом.

## Найденные расхождения в исходниках
- `Balance.pdf` (переданный файл `Balance-compressed.pdf`) содержит **1 страницу**, а не 3: блоки FAQ/контактов спроектированы по описанию в спецификации в визуальной системе страницы 1.
- Спецификация: уровень Expert; PDF: Pro → ключ `expert`, подпись настраивается.
- Спецификация и JPG: «Popularity» сортировка — данных о популярности нет, используется «Рекомендуемые» (редакционный вес) + по названию + по уровню.
- Фигуры на JPG — реалистичная женщина (заглушки макета); во всех ассетах используется единый 3D-персонаж.
