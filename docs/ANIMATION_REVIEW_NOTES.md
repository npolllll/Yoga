# Замечания к анимациям для проверки преподавателем

Анимации проверены **только автоматически**: каждый из 300 кадров — пересечение тела с полом (порог −2,5 см),
скачок опоры при постановке (≤ 3 см), дрейф опор в удержании (≤ 1 см), запас центра масс над опорой
(≥ −4 см). Анатомическую корректность автоматические проверки не гарантируют. Ниже — известные
упрощения и отклонения, замеченные при разработке. Список не заменяет проверку: преподаватель смотрит
все 44 ролика.

## Общие ограничения персонажа и рига
- Стилизованные пропорции: голова крупнее реальной (≈ 1/5,5 роста). Влияет на перевёрнутые позы.
- В риге нет супинации/пронации голеностопа и сгибания пальцев стоп: стопа «на ребре» или с подогнутыми
  пальцами передаётся приближённо (опора на подушечку стопы).
- В стойках на голове волосы на макушке условно сжимаются примерно на 1,5 см (опора — макушка).
- Без реквизита: стойки на плечах выполнены без пледа под плечами.
- Переходы (jump-to-crow, crow-to-chaturanga, crow-to-tripod-headstand, tripod-headstand-to-crow,
  side-crow-to-eka-pada-koundinyasana-1, tuck-press-to-handstand): постер — устойчивая конечная поза,
  поэтому карточка похожа на карточку этой позы. Кадр середины перехода не используется: проверка
  центра масс выполняется на кадре постера.

## По асанам
| Асана | Что проверить |
|---|---|
| pincha-mayurasana | В удержании ноги отклонены от вертикали примерно на 30° («банан»), поясница прогнута. |
| salamba-sarvangasana | Корпус не вертикален, верх спины сильно скруглён, таз ≈ 36 см над полом (крупная голова, ограничение шеи 70°, нет пледа). |
| niralamba-sarvangasana | То же ограничение, что у salamba-sarvangasana. |
| visvamitrasana | Правая нога проходит перед правой рукой, а не лежит на ней; задняя стопа на подушечке, а не на ребре; захват стопы рукой приблизителен. |
| kasyapasana | Рука в захвате скрыта за тазом; положение стопы в полулотосе приблизительное. |
| dwi-pada-koundinyasana | Бедро упирается в локоть, а не лежит высоко на плече. |
| eka-pada-koundinyasana-1 | Задняя нога немного выше уровня таза. |
| maksikanagasana | «Зацеп» стопы за руку приблизителен. |
| tripod-headstand | Выход завершается лбом на коврике (вариант позы ребёнка). |
| jump-to-crow | Постер близок к постеру bakasana (расстояние хэшей 16 при пороге дубликата 12): постер — удержание в вороне; кадр прыжка (≈3,6 с) не выбран, потому что проверка центра масс выполняется на кадре постера, а в прыжке центр масс динамически выходит за опору. |
| eka-hasta-bhujasana | Таз поднят лишь на ≈5 см, вытянутая пятка ≈11 см над полом (опора только на руки) — внешне близко к сидению; проверить, достаточно ли для учебного примера. |
| tolasana | Таз поднят на ≈6 см (ограничение длины рук персонажа; было 3 см — поднято целью решателя), камера сбоку снизу, чтобы был виден просвет; ноги скрещены упрощённо, не полный лотос. |
| tittibhasana | Удержание переработано: было глубокое складывание с ногами ниже таза; теперь прямые ноги вперёд выше таза, камера сбоку. Ширину разведения ног и положение бёдер на плечах проверить. |
